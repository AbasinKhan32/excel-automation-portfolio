# Excel Automation Portfolio

A collection of Python scripts for automating repetitive Excel and CSV tasks using **Pandas** and **OpenPyXL**.

## What I Can Automate

* Merge multiple Excel sheets or files into one master file
* Clean and format messy Excel or CSV data automatically
* Remove duplicates and handle missing data
* Generate weekly and monthly reports
* Filter, sort, and highlight important data
* Convert and process CSV and Excel files

## Tools Used

* Python
* Pandas
* OpenPyXL

## Projects

This repository contains practical Excel automation projects built with Python.

More projects will be added as I continue learning and building.
