# Pandas Data Exploration

This folder contains notes and practice for exploring Excel data using Pandas.

## Topics Covered

- `df.head()` and `df.tail()`
- `df.shape`
- `df.columns`
- `df.info()`
- `df.dtypes`
- Missing values
- `df.describe()`
- Unique values
- `value_counts()`
- Duplicate data
- Basic statistical analysis

## Tools Used

- Python
- Pandas
- Microsoft Excel
